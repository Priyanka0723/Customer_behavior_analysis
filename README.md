# ☕ Coffee Shop Sales Analysis (Excel Dashboard)

## 📌 Project Overview

This project is an end-to-end **Sales Analysis Dashboard built entirely in Microsoft Excel**. It focuses on transforming raw coffee shop sales data into meaningful insights using Excel’s powerful data analysis and visualization features.

---

## 🎯 Objectives

* Analyze overall sales performance
* Track customer footfall and order behavior
* Identify top-performing products and categories
* Compare performance across store locations
* Understand time-based sales trends

---

## 📊 Key Performance Indicators (KPIs)

* 💰 **Total Sales:** $698,812.33
* 👣 **Total Footfall:** 149,116
* 🧾 **Average Bill per Person:** 4.69
* 📦 **Average Orders per Person:** 1.4

---

## 📈 Dashboard Insights

### ⏰ Hourly Sales Analysis

* Peak sales between **8 AM – 10 AM**
* Gradual decline after evening hours

### 🥐 Category Contribution

* Coffee contributes the highest share (**39%**)
* Tea and Bakery follow as major contributors

### 🥤 Order Size Analysis

* Regular and Large sizes dominate orders
* Small size has the lowest contribution

### 📍 Store Location Performance

* Hell’s Kitchen leads in revenue
* Astoria shows highest footfall
* Lower Manhattan maintains steady performance

### 🏆 Top Products

* Barista Espresso
* Brewed Chai Tea
* Hot Chocolate
* Gourmet Brewed Coffee
* Brewed Black Tea

### 📅 Weekly Trends

* Highest orders on **Friday & Monday**
* Lowest on **Saturday**

---

## 🛠 Tools & Techniques Used (Excel Only)

* Microsoft Excel
* Data Cleaning (TRIM, handling blanks, formatting)
* Pivot Tables & Pivot Charts
* KPI Dashboard using Shapes & Formula Linking
* Conditional Formatting
* Slicers (Day & Month filters)
